A short, funny rant about an everyday annoyance — one reply-all "Thanks!" that snowballs into an 84-message thread nobody understands — written for make.fun's "Angry Judge: The Short Rant Contest" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes one rant (314 characters, single line) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and verifies the gate itself: UTF-8 text, 1 to 400 characters, not only whitespace.
